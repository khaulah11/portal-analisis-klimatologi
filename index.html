ℹ️ About the Portal

The Climatology Analysis Portal MetMalaysia Sabah is an automated meteorological analytics system built to process, quality-control, and visualize precipitation data from Automatic Agricultural Weather Stations (AAWS) across Sabah.

Developer: Sabah Meteorological Office (MetMalaysia Sabah)

Version: 2.0 (Custom Full-Stack Dashboard Edition)

Standards: World Meteorological Organization (WMO-No. 1203 / ETCCDI)
